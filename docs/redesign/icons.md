# Icons

One icon per command or element, in `icons/<id>.svg`: a 24 × 24 grid, a stroke of 1.6, round caps and joins, `stroke="currentColor"` (filled parts use `fill="currentColor"`). An icon takes the colour of its widget's text. Sizes in use: 22 px (large ribbon button), 15 px (small button, tree), 14 px (rows). Screen: `screens/11-icons.png`.

The designer's ids were French; each file was renamed to the English id below (#723). The French id is kept so the designer's screens and HTML sources can still be read. The name is the one the user reads, quoted as the interface writes it.
